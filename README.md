Project Overview
Tamkeen is a comprehensive, humanitarian-driven mobile application specifically designed to support school students. The platform bridges the gap between students in need and willing volunteers or donors, facilitating a seamless and secure environment for submitting and fulfilling humanitarian service requests.
Technology Stack: Flutter (Frontend), Node.js with Express.js (Backend), MongoDB Atlas (Database)

Team Structure
The Tamkeen project was developed by a dedicated two-member team, with each member contributing specialized expertise to deliver a fully functional cross-platform mobile application.





Full-Stack Mobile Developer, System Architect, and Designer
Responsibilities & Contributions
Backend Development
Designed and implemented the complete RESTful API architecture using Node.js and Express.js
Configured and managed MongoDB Atlas cloud database with proper IP whitelisting and network security
Developed secure authentication system using JWT (JSON Web Tokens) and Bcrypt for password hashing
Created role-based access control (RBAC) system for students and volunteers
Built comprehensive API endpoints for user registration, login, profile management, and password updates
Implemented request management system allowing students to create requests and volunteers to accept them
Configured CORS policies and environment variable (.env) security
Successfully transitioned the backend from localhost to production cloud hosting (Replit/Render)
Frontend Development (Flutter)
Developed the complete Flutter mobile application architecture
Implemented HTTP integration using the HTTP package for API communication
Created a centralized ApiService class with global exception handling
Built dynamic token injection system for authenticated API requests
Designed and coded the user interface for both student and volunteer pathways
Handled complex state management and asynchronous operations
Implemented comprehensive error handling for network failures (401, 403, SocketException)
System Architecture & Technical Problem-Solving

2.JWT authentication and token management across mobile sessions
3.Real-time state management and asynchronous data handling
4.CORS configuration for cross-origin requests
5.Production deployment and environment configuration
6.Error handling and user feedback mechanisms
